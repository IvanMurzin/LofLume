# Блокнот

Клик по блокноту на столе открывает один свободный лист. Он участвует в «Осмотреться», подсветке hover и клавиатурной навигации. Enter/пробел открывают карточку, Escape/крестик/клик снаружи закрывают. При закрытии через Escape или крестик фокус возвращается предмету.

Три иконки внизу слева: код — «Исходный Markdown», карандаш — «Live Preview», книга — «Читать»; названия доступны при наведении и с клавиатуры. «Live Preview» оформляет текст при вводе: заголовки, маркеры списков, жирный/курсив, цитаты и код оформляются сразу при вводе. Разметка показывается, когда каретка касается её или редактирует выделенный фрагмент; Home позволяет вернуть курсор к началу заголовка и изменить #. Enter продолжает список, Backspace/пустой пункт помогают выйти из него. История undo/redo и позиция каретки сохраняются при переключении режима. «Читать» показывает полное форматирование. Поддерживаются CommonMark-заголовки, жирный/курсив, списки, ссылки, цитаты, код, разделители и Markdown-картинки. Таблицы/GFM, подсветка синтаксиса, несколько документов, toolbar и отдельные задачи не добавлены. HTML не выполняется. URL фильтруются стандартным react-markdown, ссылки открываются отдельно с noopener/noreferrer. Подробности библиотеки: https://github.com/remarkjs/react-markdown.

Исходник сохраняется сразу при вводе как строка в localStorage по ключу loflume.notes.v1. Закрытие и перезагрузка сохраняют точные переносы строк и символы. При запрете/переполнении хранилища текст работает в памяти вкладки, карточка сообщает о неудаче сохранения; восстановление предыдущей записи не очищает её автоматически.

Музыка, плеер кассеты и выбранный режим часов продолжают работать. Панель выбирает свободную позицию без перекрытия внешнего экрана; на узком экране может быть ниже него. Длинный текст/код прокручивается внутри листа.

Проверки: output/notebook-checks.json — ввод, точное восстановление, Markdown, небезопасный HTML/URL, сохранение при закрытии, отказ хранилища; output/notebook-layout-checks.json — музыка, секундомер, сохранение iframe и размещение на четырёх размерах. Владелец принял блокнот с тремя режимами 25 октября 2026 и разрешил публикацию единым коммитом.

Live Preview реализован CodeMirror 6 с Markdown syntax tree и decorations: оформление не изменяет исходник. Редактор загружается при первом открытии блокнота. При чтении он остаётся смонтированным со своей историей, при закрытии не удерживает фокус, при размонтировании уничтожается. Markdown-картинки в редактировании остаются исходной записью; в чтении отображаются как изображения. Сложные Obsidian-расширения (wikilinks, embeds, плагины) не добавлены.

Направленные проверки Live Preview: tests/live-markdown.test.mjs и output/live-notebook-checks.json.

Режим исходника показывает весь Markdown моноширинным текстом без живых decorations. Тот же экземпляр CodeMirror переключает оформление через Compartment, не пересоздавая документ и историю. Разделение undo-групп при смене режима сохраняется. Проверки: output/notebook-source-checks.json.
