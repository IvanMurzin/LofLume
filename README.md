# LofLume

Уютная lo-fi-вкладка для кодинга: сцена — это интерфейс.

Стек: React + TypeScript + Vite, обычный CSS, без сервера.

Первая версия: одна домашняя комната, оригинальная девушка за компьютером,
тёплый вечер без дождя, бесплатная lo-fi-подборка, часы-таймер и лампа.
Разработка идёт через пять этапов с продуктовой приёмкой каждого.

## Сейчас: первая версия принята

Подключена обновлённая иллюстрация v6, предоставленная пользователем: со словарём, утконосом, кассетами и стаканом кофе; пользовательский SVG используется как лого и favicon. Прежний пар убран, поскольку у нового стакана крышка. Персонаж и композиция неподвижны. Кнопка
«Осмотреться» подсвечивает силуэты радио, часов и лампы и показывает
рукописные подписи со стрелками примерно на четыре секунды с плавным появлением
и исчезновением; повторное нажатие продлевает показ.
Escape убирает подписи. Наведение мышью или клавиатурный фокус подсвечивают
только выбранный предмет без текста. В правом верхнем углу — полноэкранный просмотр,
если браузер его поддерживает. На обычном десктопном экране сцена заполняет область между верхней и нижней панелями; на узких и сверхшироких экранах вписывается целиком. Предметы остаются доступны.

Нажми на радио: откроется небольшое управление. Музыка запускается только кнопкой «Включить».
«Радио LofLume» предоставляет паузу и громкость; ручного переключения нет. Закрытие управления не останавливает
музыку; подборка повторяется по кругу. Громкость сохраняется на устройстве,
автозапуска после перезагрузки нет. Пока музыка играет, внизу слева видна бегущая строка с названием и ссылкой
на автора, в том числе при закрытой панели. На паузе строка скрывается.
Плеер находится поверх картинки с отступом 12 px от нижнего левого угла. Пауза и продолжение доступны одним кликом. Наведение мыши не останавливает прокрутку; клавиатурный фокус ссылки автора останавливает её, а reduced-motion показывает статичный текст.

Шесть инструментальных треков Holizna — Chill Beats (Collection), CC0 1.0.
[Источник](https://opengameart.org/content/chill-beats-collection),
[лицензия и изменения файлов](public/audio/NOTICE.md),
[каталог и контрольные суммы](docs/assets/music-catalog.json).

Нажми часы: доступны одинаковые цифровые поля часов/минут/секунд, от 00:00:01 до 03:00:00 (00:25:00 по умолчанию), старт, пауза, продолжение и сброс. До старта и после сброса дисплей показывает 00:00; во время сессии — реальный обратный отсчёт. Карточка всегда содержит часы, минуты и секунды; все три поля редактируются до запуска, секунды по умолчанию равны 00. Клик выделяет значение целиком, повторный ввод и вставка заменяют его без блокировки каретки. После старта те же поля показывают живой отсчёт. Все три поля автоматически ограничиваются допустимым максимумом без сообщений об ошибках; общий предел — 3 часа. Двоеточие на часах мягко мигает. Закрытие панели не останавливает таймер; при возвращении в вкладку время пересчитывается по сроку завершения. Завершение отмечается более заметным мягким сигналом из трёх повторов (около четырёх секунд), с настройкой громкости от радио и полупрозрачным уведомлением над часами. Клик по уведомлению или часам плавно закрывает его. Нулевая громкость радио отключает сигнал. Заголовок вкладки во время сессии показывает `LofLume | MM:SS`, на паузе удерживает время; сброс возвращает название комнаты. Перезагрузка сбрасывает таймер. Лампа одним нажатием плавно приглушает всю сцену, вторым возвращает обычный свет. Свет и громкость сохраняются только в localStorage этого браузера; при недоступном хранилище управление работает в текущей сессии. Таймер после перезагрузки сбрасывается, музыка сама не запускается.
Декоративное движение отключается при системном уменьшении движения и
ставится на паузу в фоновой вкладке. Первая версия принята владельцем 24 октября 2026. Проверены Chrome, пять размеров, ввод таймера, сигнал, клавиатура/касание и восстановление после ошибок; публичный сайт прошёл проверку. Требование обязательной 45-минутной сессии отменено владельцем. Фактически подтверждены 10 минут воспроизведения с естественными переходами; настоящая скрытая вкладка и Safari/WebKit в этом окружении не подтверждены.

## Пробная итерация: кассеты

Стопка рядом с утконосом открывает три слота со ссылками на YouTube / YouTube Music, Spotify и Яндекс Музыку. Сохрани ссылку и подпись, затем нажми «Поставить»: механический звук, название кассеты на радио и перетаскиваемый экран над ним. Подборки сохраняются локально; после reload музыка ждёт явного запуска. «Достать кассету» возвращает обычную подборку со звуком извлечения. Яндекс получил компактные предыдущий/пауза/следующий. Локальные правки от 25 октября ожидают утверждения перед push/deploy. [Сценарий, поддержанные ссылки и ограничения](docs/CASSETTES.md).

## Локальный запуск

Node.js >=22.12, pnpm 11.25.0:

```sh
pnpm install --frozen-lockfile
pnpm dev --port 5173 --strictPort
```

Открыть локальный адрес, напечатанный Vite (обычно http://127.0.0.1:5173/).
Команды приложения поддерживают установленный Node и Node из Codex.

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm preview --port 4173 --strictPort
pnpm spec:validate
```

Сборка находится в `dist/`; разработка в `src/`, материалы в `public/assets/`.
Выбранная пользователем иллюстрация и сохранённый исходник описаны в
[паспорте материала](docs/assets/cozy-coding-v6.md).

## Устройство приложения

- `src/App.tsx` — композиция комнаты и управление панелью радио.
- `src/SceneArtwork.tsx` — исходные SVG-контуры, рукописные подсказки и действия предметов.
- `src/useRoom.ts` — осмотр, fullscreen, загрузка картинки и видимость декораций.
- `src/useMusic.ts` — подключение аудиомодуля к React и сохранение громкости.
- `src/music.ts` — независимое музыкальное состояние, каталог в `src/tracks.ts`.
- `src/timer.ts`, `src/useFocusTimer.ts` — расчёт отсчёта и его подключение к React; `ClockDisplay`/`TimerPanel` — дисплей и управление.
- `src/useTimerFeedback.ts`, `src/timerChime.ts`, `src/TimerNotice.tsx` — заголовок вкладки, короткий оригинальный сигнал и уведомление завершения.
- `src/style.css` — оформление; миграция на React не меняла CSS и материалы.
- Цифровые поля используют локальный [DSEG7 Classic Light](docs/assets/dseg-font.md), SIL OFL 1.1.

Подписки и таймеры освобождаются при размонтировании; в разработке включён React StrictMode.

## Публикация

Текущая версия публикуется на GitHub Pages через `.github/workflows/pages.yml`. Пуш готового этапа в `main` запускает типы, тесты, OpenSpec, сборку и публикацию. Изменения только в документации деплой не запускают; предусмотрен ручной запуск.

Правки по обратной связи накапливаются локально и коммитятся/пушатся одним осмысленным блоком, а не после каждого небольшого запроса.

[Настройка и проверка размещения](docs/DEPLOYMENT.md).
