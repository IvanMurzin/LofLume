# Design

## Context

Комната React/TypeScript/Vite, UI сейчас на русском; state часов, музыки, записей и кассет локален. Словарь с глобусом на верхней левой полке v6 ещё не интерактивен.

## Goals / Non-Goals

**Goals:** автоматическое начало, сохранённое ручное предпочтение, расширяемая локализация без сброса работающей комнаты.
**Non-Goals:** геолокация, перевод данных пользователя и сторонних iframe, загрузка переводов с сервера.

## Decisions

- Отдельные en/ru каталоги; английский определяет ключи, остальные проверяются через satisfies. Реестр хранит каталог, nativeName и направление текста. Translation helper подставляет именованные параметры; React продолжает экранировать значения.
- Небольшой Context provider со стабильным setPreference, без новых библиотек. Ключ localStorage loflume.locale.v1 хранит только явный код; auto удаляет ключ. Неподдержанный/повреждённый код возвращает авто. Navigator.languages проверяется по порядку с региональным fallback; languagechange обновляет автоматический выбор.
- Компоненты не хранят готовые переведённые ошибки в state: сохраняют код или флаг и переводят при render. Чистые функции часов принимают словарь отображения; расчёт времени не зависит от локали.
- Переименование aria/placeholder/title в существующем editor обновляется через CodeMirror Compartment. Не использовать locale как React key и не менять iframe src; музыка/история редактора/таймеры не пересоздаются.
- Собственные названия RU/EN используют nativeName в меню. Нейтральные Home Work, Lofi · chill · focus, Markdown и бренд сохраняются. Авторские треки и уже сохранённые имена кассет не переводятся.

## Risks / Trade-offs

- [Длинный английский текст] → осмотр и панели проверить визуально на desktop и узких размерах.
- [Хранилище запрещено] → выбор работает в памяти и меню предупреждает, что он действует в этой вкладке.
- [Будущие языки] → реестр и полные каталоги; RTL можно зарегистрировать, но новый язык требует визуальной проверки перед публикацией.
