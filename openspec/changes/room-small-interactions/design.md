# Design

## Context

См. proposal.md. Сцена v6 имеет единую систему координат SVG 1671×941. Существующие контуры приняты владельцем.

## Goals / Non-Goals

**Goals:** встроенные контуры и компактные отклики, безопасная будущая замена заглушки.
**Non-Goals:** обработка платежей, внешние скрипты, аккаунты и звуки игрушки.

## Decisions

- Два SVG-контура добавляются без редактирования иллюстрации. Система hover остаётся общей; чашка и игрушка не включаются в осмотр, контур лампы исключён из общей подсветки.
- Один локальный компонент содержит сообщения и таймер закрытия, хранит только активный предмет и индекс факта. Повторный клик не создаёт новые элементы или параллельные таймеры.
- Небольшая HTML-плашка расположена в координатах сцены над предметом; ограничена шириной сцены, не закрывает предмет. Цвета текущего интерфейса, мягкий fade, reduced-motion без анимации.
- Факты в src/platypusFacts.ts: стабильный id, RU/EN и первичный источник. Выбор равномерно из N-1 вариантов кроме предыдущего; смена языка переводит текущий факт без нового выбора.
- Поддержка остаётся честной заглушкой, без придуманного URL, пустой ссылки и платёжного iframe. Реальная ссылка будет отдельной конфигурацией после регистрации владельца.

## Risks / Trade-offs

- Небольшие предметы на телефоне → проверить границы сообщений и нажатие, сохранить desktop-first масштаб.
- Чашка, утконос и лампа исключены из осмотра; контуры hover и клавиатурного фокуса сохранены.
- Каталог фактов пополняется только короткими записями с проверенным источником.
