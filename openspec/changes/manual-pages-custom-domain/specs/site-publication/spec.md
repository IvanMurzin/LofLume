# Spec Delta

## Purpose

Публикация LofLume позволяет владельцу выбирать момент обновления сайта на GitHub Pages и предоставлять посетителям постоянный собственный HTTPS-адрес.

## ADDED Requirements

### Requirement: Ручное управление публикацией
Система SHALL публиковать сайт только после ручного запуска владельцем workflow из main; push SHALL запускать проверки без публикации.

#### Scenario: Push не меняет опубликованный сайт
- **WHEN** в main отправлены изменения приложения
- **THEN** запускаются проверки и сборка, а опубликованная версия остаётся прежней

#### Scenario: Публикация кнопкой
- **WHEN** владелец выбирает main и нажимает Run workflow и все проверки успешны
- **THEN** проверенная этим запуском версия публикуется на GitHub Pages

#### Scenario: Ошибка проверки
- **WHEN** ручной запуск завершается ошибкой типов, тестов, спецификаций или сборки
- **THEN** публикация не выполняется и опубликованная версия остаётся прежней

#### Scenario: Запуск другой ветки
- **WHEN** workflow вручную запущен для ветки, отличной от main
- **THEN** эта версия не публикуется

### Requirement: Собственный HTTPS-адрес
Сайт SHALL обслуживаться GitHub Pages по https://loflume.murzinstudio.com/ после подключения домена, с рабочими ресурсами в корне адреса; Cloudflare SHALL использоваться для DNS.

#### Scenario: Загрузка комнаты
- **WHEN** посетитель открывает собственный домен после настройки DNS и HTTPS
- **THEN** комната, шрифты, динамические материалы и локальная музыка загружаются без обязательного префикса /LofLume/

### Requirement: Понятный переход между адресами
Инструкция перехода SHALL объяснять настройку DNS, Pages и HTTPS, ручной деплой и откат, а также отсутствие автоматического переноса браузерных данных между адресами.

#### Scenario: Подготовка заметок к переходу
- **WHEN** владелец готовится переключить домен
- **THEN** инструкция предлагает заранее скопировать Markdown со старого адреса и поясняет отдельное хранилище нового адреса
