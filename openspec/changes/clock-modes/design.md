# Design

## Context

Существующие timer.ts и useFocusTimer используют deadline, карточка три одинаковых поля DurationInput. ClockDisplay рисует SVG-сегменты; useTimerFeedback управляет заголовком, звуком и уведомлением. Нужны три режима без изменения сцены и музыкальной логики.

## Goals / Non-Goals

**Goals:** один активный режим, стабильная карточка, точная пауза и фоновые обновления, явные переходы.
**Non-Goals:** сервер, постоянное хранение сессий, круги секундомера, статистика.

## Decisions

- Новый чистый reducer clock.ts хранит выбранный режим, независимые сессии и настройки помодоро; переиспользует timerReducer для обратных отсчётов. Один hook и один interval; смена режима синхронизирует и приостанавливает прежнюю сессию.
- Секундомер использует накопленные миллисекунды и отметку старта, отображает целые секунды вниз. Таймер продолжает округлять остаток вверх. Большой отсчёт содержит HH:MM:SS; часы в сцене сохраняют MM:SS (после часа — суммарные минуты), чтобы не мельчить цифры.
- Помодоро хранит завершённые фокусы 0–4 и текущий этап. При ручном завершении следующая длительность видна в карточке до запуска, физические часы остаются на 00:00. Автопереход начинает следующий отрезок от now, не прокручивает пропущенные циклы.
- Событие завершения с монотонным id отделено от phase: сигнал сработает даже если автопереход сразу вернул running. Смена режима/сброс убирают старое уведомление. Сигнал не прекращается только из-за автоматического старта следующего этапа.
- Три равные кнопки режимов, один ряд цифровых полей, постоянная строка контекста и действий. У секундомера поля заменены семантическим readout, у помодоро — значением этапа; надписи Часы/Минуты/Секунды остаются. Настройки помодоро раскрываются отдельно; длительности заблокированы до сброса начатого цикла, автопереход можно менять в процессе.
- Настройки длительностей сохраняются в localStorage с проверкой и безопасным fallback; активная сессия после reload не сохраняется. Нет дополнительных пакетов.

## Risks / Trade-offs

- [Таймеры фоновой вкладки замедляются] → elapsed/deadline по Date.now, синхронизация visibility/pageshow; браузер может задержать сам звуковой сигнал до пробуждения.
- [Несколько часов работы] → чистые тесты с управляемым now, без требования ждать реальные 25/45 минут.
- [Пересечение с плеером] → существующие позиции карточки и проверка на нескольких размерах с установленной кассетой.
