# Proposal

## Why
Пользователь хочет включать мягкий дождь на улице в Café Terrace вместе с приятным дождевым звуком. Веранда и предметы должны оставаться сухими.

## What Changes
- Небольшой переключатель с облаком на правой деревянной стойке кафе; подсказка при осмотре.
- Маскированные капли только в открытой части пейзажа, без перекрытия переднего плана.
- Мягкий независимый звук дождя с плавным включением и выключением.
- Выключение при выходе из кафе; без автоматического запуска и изменений других спейсов.

## Capabilities
### New Capabilities
- `scene-weather`: управляемая атмосфера сцены с маской внешнего пространства и звуком.
### Modified Capabilities
Нет.

## Impact
React-компонент дождя, Canvas-маска, Web Audio, RU/EN и стили. Без новых зависимостей, сторонних запросов и изменений картинки. Гром и изменение освещения не входят в этап.
