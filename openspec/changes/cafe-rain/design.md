# Design

## Context
Кафе использует иллюстрацию 1672×941 и масштабирует все элементы в координатах исходника.

## Goals / Non-Goals
Добавить спокойный дождь и звук по одной кнопке. Не менять существующую геометрию утилит и не добавлять погоду в остальные комнаты.

## Decisions
- Canvas поверх изображения, под интерактивными контурами, pointer-events none. Отдельная маска в координатах исходника вырезает навес, стойки, табличку, девушку, ноутбук, лампу, перила и стол. Нижняя граница дождя проходит за перилами.
- Рендер ограничен 30 кадрами/сек и DPR 1.5. При скрытой вкладке RAF останавливается, при reduced-motion используется статический слой. React не обновляется покадрово.
- Звук синтезируется локально: непрерывный стереофонический шум дождя с мягкими нерегулярными каплями, без грома. Это собственная генерация, без лицензирования сторонних записей и сетевой загрузки.
- Web Audio создаётся по пользовательскому нажатию; gain плавно меняется, при выключении контекст закрывается после затухания. При unmount закрывается сразу. Повторные клики не создают несколько потоков, ошибка запуска показывается локально и допускает повтор.
- Небольшая латунная пластина с облаком и рычажком на правой стойке, нарисованная SVG в координатах сцены. Доступное RU/EN название, aria-pressed, Enter/Space, расширенная прозрачная область клика. При «Осмотреться» появляется рукописная подсказка. Кнопки в верхней панели нет. По умолчанию выключено, автозапуска и сохранённого enabled нет.

## Risks / Trade-offs
Маска привязана к текущей иллюстрации и должна пересматриваться при замене картинки. Синтезированный звук требует субъективной оценки владельцем. Аудио продолжает работать в фоновой вкладке, визуальный слой при этом спит.

## Migration Plan
Изолированная возможность только Café Terrace. Нет миграции данных.
