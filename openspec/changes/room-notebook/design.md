# Design

## Context

Текущая сцена v6 содержит блокнот внизу по центру; контуры — SVG 1671×941. Панели управляются App, внешнее окно плеера draggable и должно оставаться видимым. Часы и музыка независимы.

## Goals / Non-Goals

**Goals:** один локальный Markdown-лист без отдельного приложения и без потери текста при закрытии.
**Non-Goals:** несколько документов, task management, аккаунты, синхронизация, MDX/HTML, редактор с toolbar.

## Decisions

- NotesPanel в scene-viewport, ширина 360 px, тёплая коричневая рамка и спокойный лист внутри. Иконки редактирования/чтения внизу слева; Live Preview и просмотр одинаковой высоты. Открытие других инструментов закрывает блокнот, сохраняя текст. На узком/низком экране панель остаётся слева от/ниже внешнего окна.
- Сохранение исходника синхронно на input через localStorage ключ loflume.notes.v1: один текст, без markdown-conversion при записи. Исключения хранилища показывают предупреждение; никаких сторонних запросов для сохранения.
- react-markdown рендерит CommonMark в React без dangerouslySetInnerHTML и без raw HTML-плагина. Ссылки открываются в отдельной вкладке с noopener/noreferrer, стандартный URL sanitizer сохраняется. Синтаксическая подсветка и GFM-расширения не требуются для первой версии.
- Для соседства с draggable-плеером NotesPanel измеряет iframe и выбирает позицию без пересечения; следит за resize и перемещением плеера. Сессии времени и iframe не пересоздаются от ввода заметки.

## Risks / Trade-offs

- [Хранилище переполнено/запрещено] → текст остаётся в памяти, предупреждение о несохранении; не стирать существующую запись автоматически.
- [Большой Markdown] → независимый лист с overflow и переносом длинных слов, отсутствие тяжёлого редактора; preview монтировать только в режиме чтения.
- [Длинный код/картинки] → локальные overflow/max-width, не раздвигать панель.

## Sources

- https://github.com/remarkjs/react-markdown — API, CommonMark, default URL transform и отказ от raw HTML.

## Live Preview refinement

CodeMirror 6 заменяет textarea: Markdown syntax tree определяет оформление; decorations меняют отображение, не изменяя документ. Это сохраняет точный исходник и историю; rich-text редактор с сериализацией отвергнут из-за нормализации/возможной потери Markdown. Маркеры заголовка и inline-выделения скрываются, когда каретка не редактирует их; при попадании в разметку показываются. Bullet заменяется визуальной точкой; Enter/Backspace используют штатные Markdown-команды. Код не интерпретируется как Markdown, HTML не исполняется. React получает обновления только на изменение документа, editor не пересоздаётся на каждый символ. При переключении в чтение экземпляр остаётся смонтированным для сохранения caret и undo; при закрытии освобождает фокус, при unmount уничтожается.

Третий режим «Исходный Markdown»: одна Compartment включает/выключает Live Preview в существующем CodeMirror. В source остаются Markdown keymap и моноширинный текст; decorations отсутствуют. Нижние иконки — код, карандаш, книга. Смена оформления не меняет документ, selection и историю.
