# Proposal

## Why

Владелец выбрал один свободный лист с Markdown как следующую функцию комнаты. Блокнот на столе позволяет записать мысль без выхода из атмосферной вкладки.

## What Changes

- Контур блокнота, hover и рукописная подсказка при осмотре.
- Одна компактная карточка с режимами «Писать» и «Читать», без списка документов.
- Markdown: заголовки, выделение, списки, ссылки, цитаты и код; исходный текст сохраняется автоматически в этом браузере.
- Повторное открытие и reload сохраняют заметку; закрытие карточки не меняет музыку и часы.
- Не входят: несколько страниц, отдельный task manager, синхронизация, аккаунт, редактор с панелью инструментов, загрузка файлов.

## Capabilities

### New Capabilities

- `room-notebook`: один локальный Markdown-лист через предмет сцены с редактированием, просмотром и сохранением.

### Modified Capabilities

Нет опубликованных основных спецификаций.

## Impact

Новый React-компонент блокнота и hook сохранения, SceneArtwork/App и CSS; библиотека безопасного Markdown-rendering без выполнения HTML. Существующие часы/радио/кассеты не меняют поведения.
