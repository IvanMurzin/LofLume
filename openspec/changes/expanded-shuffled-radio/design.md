# Design

## Context

См. proposal.md. SceneMusic сейчас хранит индекс каталога, начинает с 0 и переходит по модулю длины; wrap уже реализован. Причина сообщённой остановки пока не воспроизведена: не считать её доказанным отсутствием зацикливания. useMusic создаёт плеер на время жизни комнаты. Существующие тесты проверяют фиксированные индексы. Основные specs пусты; принятая база scene-music остаётся в cozy-coding-room, где требование последовательного порядка заменяется этим согласованным follow-up.

## Goals / Non-Goals

**Goals:** простая проверяемая очередь в независимом от React плеере; воспроизводимая проверка переходов и документированное происхождение аудио.

**Non-Goals:** сохранение истории между посещениями, синхронизация очередей комнат и изменения внешних кассет.

## Decisions

- Fisher–Yates над массивом индексов каталога. state.index остаётся индексом исходного каталога; отдельный курсор обозначает место в очереди. На новом круге при совпадении первого трека с предыдущим последним поменять первый элемент с другим случайным элементом. Независимый случайный выбор каждого трека отвергнут: допускает ранние повторы и пропуски.
- Генерировать очередь один раз при создании SceneMusic и на границе круга; pause/resume и retry её не меняют. Добавить возможность передать генератор случайных чисел для детерминированных тестов без статистических нестабильных утверждений.
- Сохранить локальные MP3: текущий каталог уже использует Holizna CC0. Кандидаты: https://opengameart.org/content/chill-beats-collection и дополнительные сборники профиля https://opengameart.org/users/holizna, а также https://freemusicarchive.org/music/holiznacc0/lo-fi-and-chill. Страницы проверены 2026-11-03; точный набор выбирается при проверке доступных файлов и лицензий. Ничего не покупать. Исключить дубликаты, вокальные и явно неподходящие композиции.
- Сохранить текущий формат MP3 128 kbps / 44.1 kHz и нормализацию -19 LUFS / -2 dBTP / LRA 8. Записать длительности, размеры и SHA-256 в каталог происхождения, обновить NOTICE. Исходные архивы не коммитить. Плеер не предзагружает весь каталог.
- Существующую обработку ошибок и управление оставить. Проверить настоящее событие ended и переход через круг в браузере; исправлять найденную причину остановки в пределах музыкального плеера. Изменения DOM не планируются.

## Risks / Trade-offs

- [Размер публикации] → 90 минут при 128 kbps занимают примерно 86 MB; измерить итоговый размер, не добавлять исходники и дубли.
- [Источник недоступен или лицензия конкретного файла отличается] → включать только скачанные и проверенные свободные файлы; не подменять их платными или неподтверждёнными.
- [Перемешивание меняет тестовые предположения] → проверять целостность кругов и переходы через управляемую случайность, сохраняя проверки pause/retry/stale events.
- [Ограничения браузера и фонового режима] → проверка доступным браузером, честно отметить непроверенные Safari/скрытую вкладку; обязательный длительный soak не вводить.
