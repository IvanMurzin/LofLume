## Context
См. proposal.md. App содержит общие панели, однако контуры SceneArtwork и дисплей ClockDisplay привязаны к v6. FloatingPanel использует body portal; цвет должен наследоваться и в нём.

## Goals / Non-Goals
Goals: галерея + два готовых пространства без дублирования логики инструментов. Non-Goals: веранда до выбора иллюстрации, пользовательский конструктор, перенос сессий между спейсами, автоматическая публикация.

## Decisions
- Реестр сцен содержит ассет, геометрию, подписи, дисплей. Один RoomSession с ключом space.id позволяет закрыть панели, уничтожить iframe и audio при уходе. Так исключаются скрытые YouTube-плееры и одновременная музыка.
- Владелец выбрал паузу часов при уходе и отдельные музыкальные библиотеки. Снимки часов хранятся в памяти вкладки; заметки, кассеты, громкость, свет и настройки — в браузере с префиксом спейса. Старые ключи Home Work сохраняются. Перезагрузка сбрасывает активную сессию как раньше.
- Язык остаётся в существующем общем I18nProvider. Тема на documentElement применяется также к body portal; цвета CSS централизуются в переменные без изменения значений Home Work.
- Галерея открывается отдельным экраном через кнопку с сеткой в шапке. Последний спейс открывается при старте; безопасный fallback Home Work. Переход 180мс, без задержки при reduced motion; новый ассет декодируется до смены экрана, ошибка оставляет галерею.
- Иллюстрация Night Shift оптимизируется в WebP; оригинал остаётся в ignored output. В Home Work никаких новых предметов не добавляется. Ночной кофе — прежняя заглушка; спящий кот остаётся декором.

## Risks / Trade-offs
- Маленькие часы в левом верхнем углу → дисплей SVG с перспективой, проверка на нескольких размерах.
- Переход размонтирует внешние плееры → повторный запуск требует явной установки кассеты; сами три ссылки сохранены.
- Геометрия привязана к иллюстрации → проверка совмещений на исходном растре и адаптивных скриншотах.

## Visual refinement after product review
- В Night Shift все SVG используют реальные размеры исходника 1672×941. Сцена целиком вписывается в viewport: прежнее cover от правого края обрезало левую книгу/часы на высоких окнах. Home Work сохраняет свой алгоритм кадрирования.
- Контуры повторно измерены по увеличенному исходнику: блокнот учитывает дальний лист, переплёт и перекрытие рукавом; кассеты — перекрытие ноутбуком; лампа выделяет только плафон. Для книги выбран один цельный корешок. Отверстия ручек радио и чашки исключены из заливки и области клика.
- Ночной дисплей сохраняет исходную чёрную поверхность, цифры мягко светятся в её перспективе, clip не позволяет выходить на рамку.
- Галерея: два крупных превью 16:9 в два столбца, подписи с общей Manrope, постоянная стрелка перехода, приглушённый индикатор последнего спейса. Будущая веранда — компактная строка с декоративной зарисовкой, не конкурирующая с готовыми сценами. Есть явный возврат в комнату, состояния загрузки/ошибки превью и видимый keyboard focus.
